# Deploy

**Video**: 1 min — Push to GitHub, connect to Vercel, done

---

You've built a full-stack social media site with posts, comments, auth, profiles, image uploads, and security. Ship it.

## Prompt it

```text
This Next.js + Appwrite app is ready to deploy.

Walk me through deploying to Vercel:
1. What environment variables need to be set in Vercel?
2. Does the build succeed locally? (run `bun run build`)
3. After connecting the GitHub repo to Vercel, verify the deployed site works
```

## The checklist

- Push your code to GitHub
- Connect the repo to Vercel
- Set your Appwrite environment variables in Vercel's dashboard
- Deploy
- Open the live URL and test signup, posting, and comments

That's the course. You built a real, deployed, full-stack app — by prompting, not by copying code.
