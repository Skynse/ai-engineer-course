# Setup

**Video**: None (text-only) — ~1 min read

---

Install these four things. If you already have them, verify they work and move on.

## What to install

| Tool | Why |
|------|-----|
| Node.js 20+ | Runs the dev server |
| Bun | Package manager and script runner |
| Codex CLI | Your AI build partner |
| Appwrite Cloud account | Backend (free tier is fine) |

## Verify

```bash
node --version   # 20.x or higher
bun --version
codex --version
```

## Appwrite project

1. Sign up at [appwrite.io](https://appwrite.io)
2. Create a new project — name it whatever you want
3. Note the project ID (you'll need it later)

That's it. You're ready.
