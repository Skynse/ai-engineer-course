# What is CRUD?

**Video**: 1 min — The four operations every app needs

---

CRUD stands for Create, Read, Update, Delete — the four things you do with data. Every feature in this app maps to one of these.

| Operation | In this app |
|-----------|-------------|
| **C**reate | Submit a new post or comment |
| **R**ead | Load the feed or a post with its comments |
| **U**pdate | Edit a post or comment |
| **D**elete | Remove a post or comment |

We'll build Create and Read first. Update and Delete follow the same pattern once you have the basics wired up.
