# Start Fresh

**Video**: 1 min — What you're building and why you're starting from scratch

---

You're going to build a Reddit-style social site from scratch: a feed of posts, comments on each post, user accounts, image uploads, locked-down permissions, and a live deployment on Vercel.

Every lesson adds one real piece. By the end, nothing is hardcoded — it all runs on Appwrite.

![Full-stack map: Next.js, Appwrite, Codex](/assets/diagrams/lesson-01-full-stack-map.png)

Start by generating a static mockup so you can see the product before touching the backend.
